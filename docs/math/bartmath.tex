\begin{abstract}
   This a reference for the implementation of BART in \texttt{bartz}.
   Chapter~\ref{ch:full} is a self-contained model definition and MCMC
   derivation for a generalized version of BART. Compared to bartz, it
   currently lacks the variable selection Dirichlet prior and probit outcomes.
   Chapter~\ref{ch:vanilla} shows the original vanilla BART model as a special
   case of the generalized one.
\end{abstract}
